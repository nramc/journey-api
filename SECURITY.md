# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or discussions. Send a private report to [Ramachandran Nellaiyappan](mailto:ramachandrannellai@gmail.com). If GitHub private vulnerability reporting is enabled for this repository, you may also use **Security → Advisories → Report a vulnerability**.

Include the affected version or commit, steps to reproduce, and any relevant impact. Please allow time for the maintainer to investigate before sharing details publicly.
